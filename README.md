# PDF2Cite

Simples projeto de automação criado com Python, Flask e Bootstrap. O projeto recebe na entrada arquivos PDFs de artigos ciéntificos e então retorna citações prontas para o usuário copiar.

# Como usar

1. Clone o repositório:

```fish
  git clone https://github.com/Pedroo722/pdf2cite.git
  cd pdf2cite
```

2. Execute o projeto:

```fish
  python3 app.py
```

4. Acesse o projeto em: ```http://localhost:5000```.
